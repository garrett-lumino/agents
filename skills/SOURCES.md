# Vendored skills

Every skill here is copied at a pinned commit by `scripts/vendor-skill.sh`. Before a skill is kept, every non-markdown file and every shell/network instruction in its `SKILL.md` is read.
To update a skill: delete its directory and its row, re-run `vendor-skill.sh` with a new SHA, review it again, and re-apply any local patch listed below.

## Local patches

- **web-design-guidelines**: upstream SKILL.md WebFetches its rules from `vercel-labs/web-interface-guidelines@main` (unpinned) on every use. Patched to read `guidelines.md`, a copy of that repo's `command.md` @ `434b7f91364665f2f733b310ec54809bf8f37937` (191 lines of static rules; no URLs, shell, or fetch instructions).
- **shadcn**: removed `allowed-tools: Bash(npx shadcn@latest *)` (and pnpm/bunx variants), which pre-approved every shadcn CLI command, including `add --overwrite` from arbitrary registries. Also replaced the load-time injection `` !`npx shadcn@latest info --json` `` with "read `components.json`; ask before running `info`".
- **golang-{benchmark,performance,concurrency,database,data-structures}** (samber): removed the `allowed-tools` line. Every samber skill pre-approves `Bash(go:*)` (includes `go run`) and `Bash(git:*)`; benchmark/performance also pre-approve `Bash(curl:*)`, `WebFetch`, `WebSearch`. Replaces the `cc-skills-golang@samber` plugin (46 skills, all with pre-approvals).
- **huggingface-llm-trainer**: deleted `scripts/convert_to_gguf.py` (cloned llama.cpp at unpinned HEAD into /tmp, `pip install` of unpinned requirements, cmake build, `trust_remote_code=True`); added `hub_private_repo=True` / `private=True` to every `push_to_hub` in the 4 example scripts (HF repos are public by default); pinned the example `hf_jobs` script URL to a commit SHA. Notes left in SKILL.md and `references/gguf_conversion.md`.
- **refactor-module** (hashicorp): replaced two links to unpinned `refs/heads/main` SKILL.md files with a pointer to the locally vendored `terraform-style-guide`.
- **vercel-react-best-practices**: folder renamed from `react-best-practices` so it matches the skill's `name` (agentskills.io rule).
- **principle-type-system-discipline** (pstack): removed `disable-model-invocation: true` so it loads on its own when writing typed code. Upstream only runs it from `/principle-type-system-discipline` or another pstack skill.

Licensing: `vercel-labs/agent-skills` has no LICENSE file; react-best-practices and composition-patterns declare `license: MIT` in frontmatter, web-design-guidelines declares none (its vendored `guidelines.md` comes from MIT-licensed vercel-labs/web-interface-guidelines). property-based-testing is CC-BY-SA-4.0 (share-alike; LICENSE kept, keep our own skills separate). Others: MIT or Apache-2.0 (LICENSE file inside each folder).
